### approach

I design and ship AI products — from consulting problems to working systems. Industry is a variable. The craft is not.

Most people treat a model like a smarter search box. They paste context every session and hope the output holds. I take the opposite bet: **context should persist, work should be a skill, and agents should be inspectable.**

### currently

Building agent systems and an operating system other builders can clone. Turning ambiguous product problems into skills, evals, and interfaces that actually run.
