### Thesis

Most PMs treat Claude like a smarter search box. They paste context every session and hope the output holds.

I take the opposite bet: **context should persist, work should be a skill, and agents should be inspectable.** That shows up in three lines of work:

1. **AI PM OS** — a compounding workspace for product work (PRDs, discovery, red-teams, experiments).
2. **Agent skills** — reusable methods with proof, not one-off prompts (`fable-mode`, diagrams, ITR).
3. **Agentic planning in retail** — item-level plans, OTB, and MFP workflows where a wrong number costs real money.
